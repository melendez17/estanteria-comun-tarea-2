# Estantería Común
<!-- impeccable:product-schema 1 -->

## Platform
web

## Stack
Fijado por la consigna: JavaScript sin framework, Bootstrap instalado con npm y Sass para la Parte A; React con Vite para la Parte B.

## Users
Miembros de un club de lectura comunitario que buscan libros y organizan lecturas. También un estudiante que debe explicar cada decisión en una defensa.

## Product Purpose
Buscar en Open Library, organizar una lista en memoria y proponer lecturas. Un tablero separado muestra lecturas del club con filtros y resumen, sin consumir APIs.

## Capabilities and Constraints
Español. Estados Pendiente, Leyendo y Leído. Sin backend propio ni persistencia. Formularios accesibles con errores junto a cada campo. Dos aplicaciones independientes. El usuario delegó la implementación desde cero.

## Evidence on Hand
Consigna SOFT_12_Tarea_2.pdf. No hay código ni marca previos. Los miembros y libros del tablero serán datos de demostración identificados como tales. Las pruebas, mediciones y fechas de commits deben ser reales.

## Product Principles
- Priorizar comprensión del código y tareas visibles.
- Mantener separadas las dos tecnologías exigidas.
- Informar claramente errores y estados vacíos.
